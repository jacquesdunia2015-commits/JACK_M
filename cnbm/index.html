Comment utiliser l'application

📘 Manuel d'utilisation complet, avec captures d'écran : lire en ligne · PDF : guide de l'adhérent · guide de l'administrateur · manuel complet

1. Installer l'application (une seule fois, avec Internet)

  • Téléphone Android (Chrome) : ouvrez le lien, touchez le menu ⋮ puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  • iPhone (Safari) : touchez le bouton Partager ⬆️ puis « Sur l'écran d'accueil ».
  • Ordinateur (Chrome / Edge) : cliquez sur l'icône d'installation dans la barre d'adresse, ou menu → « Installer ».
  • Sans lien Internet : le fichier index.html peut aussi être copié (clé USB, WhatsApp) et ouvert directement dans le navigateur.

2. Ouvrir son compte

  1. À la première ouverture, touchez « Créer un compte ».
  2. Saisissez votre nom, votre numéro de téléphone ou votre e-mail, et choisissez un mot de passe.
  3. Notez le code de récupération affiché : il sert si vous oubliez votre mot de passe.
  4. Les fois suivantes, connectez-vous avec le même téléphone/e-mail et mot de passe. Votre compte est enregistré sur l'appareil où vous l'avez créé.

3. Remplir sa fiche (Internet pas nécessaire)

  1. Onglet 📝 Ma fiche : remplissez les champs marqués d'une étoile *.
  2. Ajoutez tous vos lieux de travail, votre photo passeport et, si vous le souhaitez, une vidéo de 2 minutes maximum.
  3. Section 9 · Pièces justificatives : photographiez ou choisissez vos documents (diplôme, carte d'identité ou passeport, carte de membre, attestation de serment, carte de service, certificats de formation…).
  4. Touchez ✅ Valider et enregistrer. La fiche reste sur votre appareil.

Vérifier son dossier

Le bouton 📄 Mon récapitulatif produit un document téléchargeable (et imprimable en PDF) avec toutes vos données et une liste de contrôle : ce qui est complet ✅, ce qui manque ❌, et si vous remplissez les conditions d'un membre en règle (carte, serment, cotisations).

4. Envoyer aux responsables (avec Internet)

  1. Touchez 📤 Envoyer aux responsables.
  2. Sur téléphone : choisissez Gmail (ou votre application e-mail). Les fichiers sont déjà joints : tapez l'adresse affichée dans le champ « À », puis envoyez.
  3. Sur ordinateur : les fichiers sont téléchargés, puis votre messagerie s'ouvre. Joignez les fichiers téléchargés (dossier « Téléchargements ») et envoyez.

5. Pour les responsables

  1. Votre conseil provincial souscrit un abonnement auprès du créateur de la plateforme et reçoit une clé d'abonnement.
  2. Créez votre compte administrateur : écran de connexion → « Je suis responsable d'un conseil provincial », puis collez la clé.
  3. Dans 🏛️ Espace responsables → Abonnement, copiez le lien d'inscription des membres et partagez-le (WhatsApp, e-mail) : chaque membre qui l'ouvre est rattaché à votre conseil.
  4. Les demandes d'adhésion des nouveaux membres apparaissent avec le filtre « Demandes d'adhésion » ; ouvrez la fiche et touchez ✅ Accepter l'adhésion.
  5. Téléchargez les pièces jointes des e-mails reçus.
  6. Onglet 🏛️ Espace responsables → 📥 Importer : sélectionnez tous les fichiers d'un coup.
  7. Recherchez, filtrez par province, ouvrez une fiche pour voir la photo et la vidéo.
  8. 📊 Liste complète en Excel : un fichier .xlsx avec toutes les personnes inscrites et toutes leurs données (3 feuilles : Membres, Lieux de travail, Formations). Relancez-le après chaque import pour avoir la liste à jour.
  9. Faites régulièrement une 💾 Sauvegarde complète et gardez-la en lieu sûr : effacer les données du navigateur efface le registre.

Confidentialité

Les données ne sont envoyées à aucun serveur par l'application : elles restent sur l'appareil jusqu'à ce que vous les envoyiez vous-même par e-mail aux responsables du CNBM.
