Démo : admin.horizon / demo1234
Ouvrir → Déployer (Render)
En local : cd nova-pharma-os && node server.mjs (port 8080) et cd medilab && PORT=8081 node server.mjs (port 8081) — les deux serveurs peuvent tourner en même temps sans conflit.
Une fois déployé sur Render (ou ailleurs), cliquez « Changer l'adresse… » sur la carte concernée pour remplacer le lien par l'URL réelle ; elle est mémorisée dans ce navigateur.
