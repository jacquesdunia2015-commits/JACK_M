QualiCode — vérifications en navigateur réel

Ce que Node ne peut pas vérifier : la vraie base IndexedDB, le vrai analyseur XML, le vrai chiffrement du navigateur. Complément de node tests/tous.mjs.

Cette page ne touche pas à vos projets. Elle travaille dans une base d'essai séparée (qualicode-tests), qu'elle supprime en terminant. Vos projets ne sont que lus, pour vérifier qu'ils sont bien là.

Elle doit être ouverte depuis un serveur (comme l'application elle-même), et non par double-clic : python3 -m http.server dans le dossier de QualiCode, puis http://localhost:8000/tests/navigateur.html.
